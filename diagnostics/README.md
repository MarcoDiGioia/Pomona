# Diagnostics

Reports of the cases where Pomona's verdict was wrong: a page said something was broken and it worked, or the other way round. Each file is a diagnostic sent with *Is Pomona wrong?* in the app (or `pomona diagnose`), checked by `tools/diagnostics.py` and added by the robot. The summary is in [docs/diagnostics.md](../docs/diagnostics.md). Do not add or edit files by hand.
